# Speed Lab concept

Open `speed-lab.html` directly in a browser. It is a self-contained HTML mockup with embedded sprites,
current roster data, and the existing calculation engine; it needs no server or network connection.

This explores a different primary interaction: choose two Pokémon, see their Speed gap, then try one
concrete change. Investment, alignment, held items, Tailwind, weather and Trick Room work directly.
Species selection and advanced set settings open in dialogs. Suggested changes are calculated from
the current matchup, can be applied, and can be undone. Benchmark buttons reset the opponent to
maximum Speed with no item.

This is a concept, not the full application: there are no saved teams, imports, sharing, persistence,
or multi-anchor tables. `speed-tiers.html` and the production GitHub Pages site are unchanged.
